# 🇹🇼 台灣加權指數（台股大盤）每日多空預測與籌碼決策系統

這是一個專門為台灣股市投資人打造的**台股加權指數 (`^TWII`) 每日漲跌預測、三大法人籌碼診斷、期貨未平倉 (OI) 分析與買賣決策系統**。

系統結合「**美股跨市場先導（台積電 ADR、費城半導體、標普500）**」、「**三大法人現貨買賣超（外資、投信、自營商）**」、「**台指期貨大台未平倉（OI）多空比**」、「**多維度技術指標共識評分**」以及「**機器學習雙模型集成**」，每天提供全方位的買賣訊號、建議持股水位、關鍵支撐/壓力位、動態停損點與策略歷史回測。

---

## 🌟 核心特色

1. **三大法人現貨籌碼（TWSE）**：
   - 每日自動追蹤**外資買賣超金額（億元）**、**投信買賣超**、**自營商買賣超**、**三大法人合計金額**。
   - 計算**外資/投信連續買賣超天數**與**5日/20日累計買賣超**，精準洞悉主力資金方向。
2. **台指期貨大台未平倉（TAIFEX Futures OI）**：
   - 即時掌握**外資大台期貨淨未平倉口數**與**多空比率 (Long/Short Ratio)**。
   - 自動判讀期貨避險與攻擊水位（如空單突破 -35,000 口重度警戒）。
3. **跨市場前導指標對齊**：
   - 納入前夜 **台積電 ADR (`TSM`)**、**費城半導體指數 (`^SOX`)**、**標普 500 (`^GSPC`)** 與 **美元兌新台幣 (`TWD=X`)**。
4. **多因子技術分析共識引擎**：
   - 全自動計算 **MA5/MA10/MA20/MA60 多空排列**、**MACD 柱狀圖動能**、**KD(9,3,3) 轉折**、**RSI(14) 超買超賣**、**布林通道** 與 **ATR(14) 真實波幅**。
5. **AI 機器學習四維度集成模型**：
   - 採用 `RandomForest` + `HistGradientBoosting` 集成架構，融合技術面 40% + 機器學習 35% + 籌碼面 15% + 美股 ADR 10%，輸出明日**上漲機率（%）**與**下跌機率（%）**。
6. **明確的五級買賣訊號與風控建議**：
   - 🟢 **強力買進 (Strong Buy)**：建議持股水位 80% ~ 100%
   - 📈 **偏多操作 (Buy)**：建議持股水位 60% ~ 80%
   - ⏸️ **觀望盤整 (Hold / Neutral)**：建議持股水位 40% ~ 60%
   - 📉 **偏空警戒 (Sell)**：建議持股水位 20% ~ 40%
   - 🔴 **強力賣出 (Strong Sell)**：建議持股水位 0% ~ 10%
   - **關鍵點位計算**：動態停損價、目標停利點、第一/第二支撐位 (S1, S2)、第一/第二壓力位 (R1, R2)、日內預期高低點。
7. **雙操作介面**：
   - **Streamlit 視覺化互動網頁儀表板**：三大法人籌碼柱狀圖、期貨 OI 走勢圖、K 線圖、AI 儀表量表與歷史回測資金曲線。
   - **終端機彩色 CLI 模式**：一秒快速輸出包含籌碼數據的大盤診斷報告。

## 🚀 快速開始

### 方式一：Windows 一鍵雙擊啟動（最推薦）
雙擊專案目錄下的捷徑：
- 👉 **`start_web.bat`**：一鍵開啟 Streamlit 視覺化網頁儀表板（瀏覽器自動開啟 `http://localhost:8501`）
- 👉 **`start_cli.bat`**：一鍵在終端機中執行快速預測
- 👉 **`run.bat`**：開啟主選單（可選擇網頁、終端機、歷史回測或匯出 Markdown 日報）

---

### 方式二：命令列手動啟動

```powershell
cd C:\Users\h1243\.gemini\antigravity\scratch\taiex_predictor

# 1. 啟動 Streamlit 網頁儀表板
.venv\Scripts\python.exe -m streamlit run app.py

# 2. 終端機快速預測 (CLI 模式)
.venv\Scripts\python.exe cli_predictor.py

# 3. 匯出今日 Markdown 格式預測日報
.venv\Scripts\python.exe cli_predictor.py --export

# 4. 執行歷史策略步進式回測
.venv\Scripts\python.exe backtest.py
```

└── README.md                  # 專案詳細使用說明
